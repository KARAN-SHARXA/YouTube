# 🎬 YouTube Clone (React + Vite)

A modern **YouTube Clone** built using **React.js** and **Vite**, created to practice real-world frontend development concepts like React Hooks, React Router, reusable components, and responsive UI design.

This project focuses on learning how large applications are structured while building a clean and interactive video platform interface.

---

## ✨ Features

- 🎥 Home page with video feed layout
- 📺 Video player page
- 🔎 Search UI
- 📂 Sidebar navigation
- 🧭 Routing using React Router
- ⚡ Fast development with Vite
- 📱 Fully responsive design
- 🎨 Clean and modern UI
- 🔄 Dynamic component rendering
- 🧩 Reusable component structure

---

## 🧠 React Concepts Used

### ⚛️ React Hooks
- `useState` → State management  
- `useEffect` → Side effects & lifecycle handling  
- `useRef` → DOM references  
- `useContext` → Global state sharing  
- `useMemo` → Performance optimization  
- `useCallback` → Function memoization  

### 🛣️ React Router
- Dynamic routing
- Nested routes
- Route navigation
- URL parameter handling
